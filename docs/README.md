# Ishita Yadav — Portfolio 2026

Motion-led portfolio website for Ishita Yadav, a fourth-year Communication Design (Fashion) student. The design is built around her `PORTFOLIO_2026.pdf`.

## Status
- `Ishita_Yadav_final_draft.html`: self-contained prototype (all images embedded, no build step). Open it in a browser or host it as a static file.
- Production version: not started. See `ROADMAP.md`.

## Documents
| File | Purpose |
|---|---|
| `PRD.md` | What we are building, for whom, and what is in or out of scope |
| `STACK.md` | Technology choices, repos, hosting, performance budgets |
| `DESIGN-SYSTEM.md` | Palettes, type, layout and image rules |
| `MOTION-SPEC.md` | Every animation, its timing, fallbacks, and the hover `CONFIG` |
| `CONTENT-ASSETS.md` | Assets and copy still needed, plus the PDF page to image map |
| `AGENTS.md` | Rules for AI coding agents (Antigravity or similar) |
| `ROADMAP.md` | 3-day plan and QA checklist |

## Running the prototype
Open the HTML file. Routing uses the URL hash (`#layout`, `#lumea`), so it works on any static host.

## Customising
Edit the `CONFIG` object near the top of the script. Every key is explained in `MOTION-SPEC.md`.
